STEP 01
Add new tabs to your existing Google Sheet
Keep your existing Transactions tab. Add these new tabs:

Config · Cards · Loans · CCBills · Payments · Income · Savings

Add header rows to each new tab
Config: Key | Value (then add rows: ef | 200000, inc | 251683, hh | 40000, prop | 6000000, assets | 0)
Cards: Name | Rate | Notes
Loans: Name | Type | EMI | Rate | StartDate | Installments | Notes
CCBills: Date | CardName | BillAmount | DueDate | Notes
Payments: Date | LoanOrCard | Amount | Notes
Income: Month | Amount | Source | Notes
Savings: Date | Amount | Notes

STEP 04
Deploy as Web App
Deploy → New deployment → Web app → Execute as: Me → Access: Anyone → Deploy → Authorize → Copy URL
STEP 05
Hardcode your URL into this file — one time only
Open index.html in any text editor. Find line 1 of the <script> section:

const API = 'PASTE_YOUR_URL_HERE';

Replace PASTE_YOUR_URL_HERE with your Apps Script URL. Save. Push to GitHub. Done — every device uses the same file, same URL, no setup per device.
STEP 06
Host on GitHub Pages (free — must be public repo)
1. New GitHub repo e.g. mg-fintrack → set Public
2. Upload index.html
3. Settings → Pages → Source: main branch → / (root) → Save
4. Wait ~2 min → URL: https://yourusername.github.io/mg-fintrack/
5. Bookmark on every device. Settings sync from Sheet automatically.
